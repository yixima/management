# 資金繰り表 雛形（Excel・3パターン）

| ファイル | 形式 | 期間 | 向いている場面 |
|---|---|---|---|
| `A_月次資金繰り表_25か月.xlsx` | 月次・三区分（経常／経常外／財務）、営業収入・未払金支払あり。営業収入は2025年10月〜2026年8月の実績入力済み | 25か月（2025年10月〜2027年10月） | 標準。年間の資金計画・金融機関への提出 |
| `B_日繰り表_1か月.xlsx` | 日次（入金・出金・差引残高） | 1か月 | 資金に余裕がない時期、月中の資金ショート防止 |
| `C_予実管理型資金繰り表_6か月.xlsx` | 月次・予定／実績／差異 | 6か月 | 計画と実績の比較、予測精度の改善 |

## 共通ルール
- 黄色・青字のセル＝入力欄。白・黒字のセル＝計算式（触らない）
- 繰越残高・合計・差額はすべて自動計算
- 残高が「最低必要残高」を下回ると赤表示＋「要注意」
- 入っている数値は**記入例**です。実際の数値に置き換えてください
- 各ファイル先頭の「使い方」シートに手順を記載
